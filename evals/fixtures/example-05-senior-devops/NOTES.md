# EXAMPLE FIXTURE — not coverage

Invented for this repo so the fixture format is unambiguous and the runner can be proved
end to end. Not a real user's resume; not coverage.

- **Shape**: nearly six years DevOps across two product companies, long tool inventory.
- **Input**: `resume.txt` — the paste path, no PDF.
- **Why this shape**: 27 labelled skills is the upper end of what this app sees, and it is
  where skill recall degrades first. It is also the only example labelled `Senior`, so a
  prompt change that collapses everything to `Mid-level` shows up here.
