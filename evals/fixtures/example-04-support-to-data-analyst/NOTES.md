# EXAMPLE FIXTURE — not coverage

Invented for this repo so the fixture format is unambiguous and the runner can be proved
end to end. Not a real user's resume; not coverage.

- **Shape**: career switch inside one employer, production support to data analyst,
  non-engineering degree (B.Com).
- **Input**: `resume.pdf` (rendered from `resume.txt`).
- **Why this shape**: two roles at one company with a role change between them. Total
  experience is 4.0 years; time in analytics is 2.5. The label is total professional
  experience, because that is what the field means — this is the fixture that catches a
  prompt change deciding otherwise.
- **Structural pin**: same margin-contact failure as example 01, from the same template.
